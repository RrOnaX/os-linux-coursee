# Операционные системы и среды

Репозиторий для выполнения практических работ по дисциплине «Операционные системы и среды».

## Цели на курс

- Изучить устройство операционных систем
- Научиться работать с GitHub
- Освоить диагностику и мониторинг системы
- Получить навыки работы с системными инструментами Windows

## Структура репозитория
os-linux-course/
├── README.md
├── assets/
│ └── screenshots/ # скриншоты для лабораторных
├── labs/
│ └── lab01/ # папка для первой работы
├── reports/ # отчёты по заданиям
└── scripts/ # скрипты для автоматизации

## Правила ведения

- Одна работа — отдельная папка в labs/
- Понятные имена файлов
- Осмысленные коммиты
- Без личных данных и секретов
